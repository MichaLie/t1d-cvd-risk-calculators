Type 1 Diabetes — Cardiovascular Risk Meta-Calculator

Runs implemented published CV risk calculators side by side for an adult with type 1 diabetes, shows where their outputs agree and diverge, and permits explicit sensitivity scaling. It is not a new prediction model — model assumptions and implementation-check status are reported below. For research and education only; not a validated clinical decision rule or regulated medical device.

Methods, implementation checks & coefficients

Each tool below is a transparent implementation of a published equation. The Node harness includes selected source-paper examples and tables, live-tool comparisons where available, and regression guards (see test_models.js); a cross-implementation parity check (parity_check.js) confirms that this browser engine reproduces the manuscript pipeline on all 10,000 synthetic profiles. These checks assess software implementation, not external clinical validity. Coefficients are supplied in models.js and the separately licensed qrisk3.js; QRISK3 is also tested against the bundled original C source. The secondary Steno-IHD/stroke coefficients were checked against Vistisen 2016 Supplemental Table 4. This is an agreement and comparison tool, not an accuracy study: without outcomes it cannot establish which estimate is correct.

Input substitutions. QRISK3 uses a simplified ethnicity mapping, current smoking as light smoking, zero SBP variability and Townsend score, and no unlisted comorbidities or medications. ADVANCE substitutes ACR 10/100/500 mg/g for the albuminuria categories. These assumptions can change the estimates.

Recalibration. The SCORE2 family uses its published risk-region mechanism. The optional multiplier scales cumulative hazard for all T1D endpoints as a sensitivity exercise. An observed/expected event-risk ratio is not generally equal to a cumulative-hazard multiplier. This control does not perform or establish local recalibration; endpoint-specific outcome data and calibration methods are needed.

Literature-only model. The Scottish–Swedish model is discussed in the literature figures but is not implemented here: the sources available to this project do not establish a complete reproducible final-model specification. See the authors’ illustrative tool.

Open-source and self-contained; patient inputs stay in the browser.
